# NEON CITY

這是一個使用 `pygame-ce` 製作的程式繪製 3D 第三人稱自由拆樓沙盒遊戲。每次
開始都會建立新的世界種子；玩家周圍維持 3×3 個城市區塊，移動到遠方時會
串流新的霓虹方塊大樓，離開的區域可在同一局中穩定重建。

## 執行

```powershell
python -m pip install -r requirements.txt
python game_3d.py
```

如果使用虛擬環境：

```powershell
.\.venv\Scripts\python.exe game_3d.py
```

## 操作

- `W` / `S`：前進／後退
- `A` / `D`：左右平移
- `Space`：跳躍
- 按住滑鼠右鍵拖曳：旋轉鏡頭；拖曳期間左鍵互動會暫停
- `1`：切換收槍／拿槍（新局開始時已有槍但收起）；收槍就是抽取模式，拿槍就是射擊模式
- 收槍時按住滑鼠左鍵拖曳至少 24 像素再放開：把最近的完整方塊抽出；
  拖曳過程中方塊會在畫面上跟隨游標；短按、拖曳不足、遠景輪廓或超過
  60 世界單位都會取消
- 拿槍時按住滑鼠左鍵：立即發射並每 6 幀連射；每個方塊需要 10 次命中才會
  進入原本的倒塌效果，子彈會沿瞄準方向可見地飛行
- `Esc`：離開遊戲

畫面會顯示持槍狀態、左鍵目前用途、目標 `0/10`–`9/10` 命中進度、唯一拆除數、
重生倒數與操作提示。背景為淺藍色，遠處城市會以不具碰撞、瞄準或射擊功能的
輪廓延伸視野；靠近後才會進入活動區並可互動。拆除支撐分段會觸發
可控的連鎖倒塌；碎片只會推開或短暫減速玩家，不會造成死亡。分段在固定 60 FPS
經過 `RESPAWN_FRAMES=1800` 幀（等同 30 秒）後依支撐順序重生；遊戲沒有勝利、
失敗或跨次存檔，掉出世界高度時會回到最近安全位置。遊戲使用 Pygame 的
透視投影繪製方塊城市，不需要外部圖片、模型、音效或其他 3D 引擎。`day1`
與 `day2` 目錄保留原本的 Pygame 練習。

第一版刻意不包含多人、網路同步、存檔、完整剛體物理、角色模型與音效資產。
