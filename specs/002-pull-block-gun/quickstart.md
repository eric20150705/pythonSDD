# 快速入門：抽取方塊與槍械

## 前置條件

- Windows 桌面環境。
- Python 3.14。
- 專案根目錄為 `C:\Users\user\OneDrive\桌面\python.sdd`。
- 已建立 `.venv`，且既有 `pygame-ce==2.5.8` 已安裝；本功能不新增第三方依賴。

## 自動化驗證

在 PowerShell 由專案根目錄執行：

```powershell
.venv\Scripts\python.exe -m py_compile game_3d.py
.venv\Scripts\python.exe game_3d.py --self-test
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

預期結果：

- `py_compile` 無輸出且結束碼為 0。
- `--self-test` 顯示 `NEON CITY self-test: all core rules ok`。
- unittest 的既有與新增測試全部通過，且不需要開啟遊戲視窗。

## 實作前基線

在功能程式碼修改前，已於 2026-08-27 執行並重新確認既有驗證：`py_compile` 結束碼 0、30 項 unittest 全部通過，`game_3d.py --self-test` 顯示 `NEON CITY self-test: all core rules ok`。後續實作不得把這些基線結果誤當成本功能已完成的驗證。

## 手動冒煙測試

實作完成後，從專案根目錄啟動遊戲：

```powershell
.venv\Scripts\python.exe game_3d.py
```

依序確認：

1. 新局一開始背景是淺藍色，玩家 HUD 顯示有槍但目前收起；遠處可看到至少一圈低成本城市輪廓；新玩家應在 60 秒內看懂初始狀態。
2. 走到建築物頂部並站立數秒：方塊不會因接觸而消失，也不會增加已破壞數；碰撞與支撐仍然有效。
3. 保持收槍，對完整近景方塊短按或拖曳少於 24 像素後放開：抽取取消，方塊與計數不變。
4. 保持收槍，按住左鍵拖曳至少 24 像素後放開：移動鼠標時確認方塊在畫面上跟隨水平、垂直及斜向位移，放開後預覽保留最後鼠標位置並進行 10 幀的抽出動畫，完成後進入原本的倒塌效果；確認失去支撐的上方分段在 2 秒內開始倒塌，重複 10 次時有支撐的分段都保持穩定，且碎片不造成死亡或永久卡住。
5. 在新局開始 60 秒內按 `1` 拿槍，確認 HUD 與畫面顯示持槍；按住滑鼠左鍵，確認第一發立即出現，之後每 6 幀連射。放開左鍵後停止。
6. 以 10 次射擊流程讓同一個方塊被子彈命中 1–9 次：HUD 顯示對應的 `n/10`，方塊仍在且支撐關係不變；第 10 次先顯示一幀 `10/10`，再觸發原本倒塌流程。
7. 再按 `1` 收槍，確認左鍵不再發射子彈，而是回到抽取模式；切換途中不會卡住抽取或持續開火。
8. 走向遠景輪廓：靠近前不能碰撞、瞄準、抽取或被子彈命中；進入活動區後才變成可互動建築，且起始場景至少維持一圈遠景輪廓。
9. 觀察至少 15 分鐘或反覆射擊/倒塌，確認子彈、碎片、特效與遠景物件受數量上限控制，畫面維持可玩且接近 60 FPS。
10. 觸發既有建築重生流程：在固定 60 FPS 下等待 `RESPAWN_FRAMES=1800` 幀（等同 30 秒），確認該建築分段的部分命中進度歸零，且既有已倒塌結果與唯一拆除數遵循原規則；若玩家重生，只確認子彈、未完成抽取與按鍵持續狀態清除，仍完整分段的部分命中不得被清除。
11. 完成至少 10 次混合抽取／射擊拆除：HUD 唯一拆除數必須等於首次失效的穩定分段數，重生或區域重載不得重複增加。

## 邊界情況

| 情況 | 預期結果 |
|------|-----------------|
| 玩家站在或碰觸建築方塊 | 只碰撞，不破壞。 |
| 收槍時短點擊／短拖曳 | 取消抽取，不產生破壞。 |
| 抽取拖曳時移動鼠標 | 目標方塊跟隨鼠標方向與距離，實際碰撞與支撐不變。 |
| 抽取動畫開始後 | 方塊維持最後鼠標位置，不跳回拖曳起點。 |
| 收槍時沒有有效目標、遮擋、超過 60 世界單位或只瞄準遠景 | 無世界變更。 |
| 抽取動畫中切換武器、失焦或按 Esc | 操作清除，不誤破壞。 |
| 持槍時左鍵放開 | 不再生成新子彈。 |
| 子彈超過 45 幀、60 世界單位或 256 發上限 | 先清除失效子彈；仍滿載時淘汰最舊活動子彈，再加入新彈，不無限增長。 |
| 子彈穿越細小/快速目標 | 掃掠判定仍能在穿越期間命中一次。 |
| 部分命中後普通重建世界清單 | 同一局的 `n/10` 保留。 |
| 建築分段倒塌／重生 | 在固定 60 FPS 下經過 `RESPAWN_FRAMES=1800` 幀（等同 30 秒）後，該分段部分命中清除；子彈與未完成操作依生命週期清除。 |
| 玩家重生但分段仍完整 | 子彈、未完成操作與按鍵持續狀態清除；該分段部分命中保留。 |
| 右鍵拖曳相機時按左鍵 | 左鍵不開始抽取或射擊。 |
| 視窗失去焦點後恢復 | 不會自動持續抽取、射擊或旋轉相機。 |
