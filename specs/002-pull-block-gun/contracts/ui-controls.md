# UI 與控制契約：抽取方塊與槍械

**功能**：`002-pull-block-gun`  
**範圍**：本地單人 Pygame 輸入、互動與 HUD 行為；不提供網路 API。

## 輸入契約

| 輸入 | 狀態／條件 | 必要行為 |
|-------|-----------------|-------------------|
| `W/A/S/D` | 遊戲執行中 | 依既有規則移動玩家；不改變建築物生命週期。 |
| `Space` | 玩家在地面 | 依既有規則跳躍；不因跳躍或落地觸發破壞。 |
| 滑鼠右鍵拖曳 | 遊戲執行中 | 依既有規則旋轉相機；右鍵拖曳期間左鍵互動不開始新的抽取或射擊。 |
| `1` | 遊戲執行中 | 切換 `Player.gun_equipped`；`Player.has_gun` 在本功能中一直為 true。切換時取消未完成抽取，並重設不適用的左鍵/開火狀態。 |
| 滑鼠左鍵按住 | `gun_equipped == false` | 開始或持續 `PullAction`，記錄按下游標位置與目前目標。 |
| 滑鼠左鍵放開 | `gun_equipped == false` | 若拖曳距離未達 24 畫面像素，取消且無世界變更；有效抽取操作完成 10 幀抽取動畫後只破壞一次。 |
| 滑鼠左鍵按住 | `gun_equipped == true` | 立即發射一發，之後每 6 幀連續發射；沒有彈藥或換彈操作。 |
| `Esc` | 遊戲執行中 | 清理按鍵持續狀態、抽取操作與開火狀態，結束遊戲。 |

視窗失去焦點時，實作必須清除左／右鍵持續狀態、相機拖曳狀態、未完成的抽取操作與開火冷卻，避免重新取得焦點後自動延續互動。

## 抽取互動契約

### 目標資格

抽取開始與完成時，目標必須同時符合：

- 位於活動 3x3 區塊；
- 是完整、未倒塌、未處於待重生／倒塌狀態的建築分段；
- 位於玩家／瞄準射線的既有 60 世界單位互動距離內；
- 是目前可見且最近的有效目標，並通過既有遮擋/射線判定。

5x5 遠景環中的輪廓不是有效目標，即使畫面看得到也不可抽取。

### 狀態轉換

```text
IDLE
  └─ 收槍時按下左鍵 ─> DRAGGING
DRAGGING
  ├─ 拖曳距離 < 24 px 後放開 ─> IDLE（取消，不變更世界）
  ├─ 失去焦點／切換槍械／Esc ─> IDLE（取消，不變更世界）
  └─ 有效目標 + 距離 >= 24 px ─> ANIMATING
ANIMATING
  ├─ 目標失效／失去焦點／切換槍械 ─> IDLE（取消）
  └─ 10 幀後 ─> IDLE（呼叫拆除一次）
```

抽取預覽可以改變目標方塊的暫時渲染位移，但不改變其 AABB、支撐關係、命中進度或破壞計數。拖曳期間，方塊的畫面位置必須依 `current_cursor - start_cursor` 的方向與距離同步跟隨游標；放開後的 10 幀動畫維持最後一次游標位置，避免預覽跳回原位。完成時必須沿用既有 `demolish_segment()`，使原本的支撐連鎖、倒塌動畫、碎片、特效與重生規則繼續生效。

## 武器與子彈契約

- 新局建立時 `has_gun == true`、`gun_equipped == false`；玩家一開始收槍。
- `1` 可反覆切換拿槍與收槍；收槍時左鍵不得建立子彈。
- 持槍左鍵按住時第一發立即建立，後續每 6 幀一發。
- 子彈必須有可見的移動表示，速度為 1.6 世界單位／幀，最長 45 幀，最多移動 60 世界單位；離開有效畫面／達任一上限時清除。
- 子彈清單最多 256 發；達上限時先清除已失效項，若仍滿載則淘汰最舊的活動子彈，再加入新發射，絕不無界增長。
- 每發子彈沿連續掃掠路徑檢查活動 3x3 中最近的有效分段，對同一發子彈最多命中一次；遠景輪廓、玩家、碎片與其他子彈不是命中目標。
- 每次命中增加目標 `bullet_hits` 一次。第 1–9 次只更新進度；第 10 次先顯示一幀 HUD `10/10` 完成回饋，再清除該分段的暫存傷害並呼叫 `demolish_segment(..., cause="bullet")` 一次。
- 同一局的部分命中以穩定分段識別保存於 `damage_overrides`，不因普通世界更新或列表重建消失；建築分段倒塌或重生時清除該分段部分命中，玩家重生不清除仍完整分段的進度。
- 子彈破壞不得改變既有唯一拆除數的語義；支撐連鎖觸發的其他方塊各自只計數一次。

## 視覺與 HUD 契約

- 世界背景填色使用淺藍色 `SKY_COLOR=(170,220,245)`。
- 近景使用既有詳細建模；遠景最多渲染 5x5 區塊的低成本建築輪廓。遠景只視覺化，不建立碰撞、目標選取或子彈命中項目。
- `gun_equipped == true` 時顯示程式化槍枝與射擊中的子彈；收槍時不顯示持槍姿態。
- HUD 至少顯示：持槍／收槍狀態、左鍵目前用途、瞄準分段的命中進度（`0/10` 至 `9/10`，第十發命中時一幀顯示 `10/10`）、已破壞數，以及既有重生倒數提示。
- 抽取動畫的方塊位移、槍枝、子彈和 HUD 都不得改變既有支撐判定或物理結果；完成破壞後必須可看見原本的倒塌效果。

## 可觀察驗證契約

以下命令是本功能的最低可重現驗證入口：

```powershell
.venv\Scripts\python.exe -m py_compile game_3d.py
.venv\Scripts\python.exe game_3d.py --self-test
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

成功條件為編譯無錯、self-test 回報核心規則通過、既有與新增 unittest 全部通過；畫面互動則依 `quickstart.md` 的手動案例驗證。
